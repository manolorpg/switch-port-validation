# Resultados dos Testes

## 1. Resumo da validação

Foram avaliadas individualmente as 24 portas Ethernet RJ45 do switch D-Link DGS-3120-24TC.

Todas estabeleceram conexão com o computador utilizado durante os testes.

## 2. Resultado consolidado

| Indicador | Resultado |
|---|---:|
| Portas RJ45 avaliadas | 24 |
| Portas aprovadas | 24 |
| Portas reprovadas | 0 |
| Taxa de aprovação | 100% |
| Velocidade observada | 1000 Mbps |
| Duplex observado | Full |

## 3. Resultado por porta

Todas as portas, da 01 à 24, apresentaram:

- Estado do link: Up
- Velocidade: 1000 Mbps
- Duplex: Full
- Resultado: Aprovada

## 4. Observações

As portas 21 a 24 possuem interfaces combo. Neste procedimento, somente as conexões Ethernet RJ45 foram avaliadas. As interfaces de fibra óptica não foram testadas.

Os resultados representam exclusivamente a condição observada durante os testes de conectividade básica.

## 5. Conclusão

O equipamento apresentou resultado satisfatório no teste básico de conectividade física das 24 portas Ethernet RJ45.

Todas estabeleceram conexão a 1000 Mbps, em Full Duplex.

**Resultado final: APROVADO NO TESTE BÁSICO DE CONECTIVIDADE DAS 24 PORTAS RJ45.**

Não foram realizados testes de desempenho, transferência de dados entre múltiplos dispositivos ou validação das interfaces de fibra óptica.
